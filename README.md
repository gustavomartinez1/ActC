# ActC — Práctica de Scaffold y Listas en Jetpack Compose

**Asignatura:** Desarrollo de Aplicaciones para Dispositivos Móviles — ITIC
**Alumno:** Gustavo Martínez Montes

App Android en Kotlin + Jetpack Compose (Material 3) que muestra:

- `Scaffold` con `TopAppBar` (botón de regreso), `BottomAppBar` y `FloatingActionButton`.
- `Snackbar` que se muestra al presionar el FAB.
- `LazyColumn` con imagen principal, contador de "likes" (se conserva con `rememberSaveable`) y datos del alumno.
- `LazyRow` con una galería horizontal de imágenes.
- Textos desde `strings.xml` (recursos localizados).

## Ejecutar
Abrir la carpeta en Android Studio y correr el módulo `app` en un emulador o dispositivo (minSdk 24).
